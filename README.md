# Wallet interaction

A leather wallet holding four payment cards. Hover to fan the cards, click one to pull it out, flip it, add or delete cards, and switch between a horizontal and a vertical wallet.

## Tech stack

- React 19
- Vite 8
- Tailwind CSS 4
- CSS transitions and 3D transforms, no animation library
- Inline SVG

## Run

```bash
npm install
npm run dev
```
